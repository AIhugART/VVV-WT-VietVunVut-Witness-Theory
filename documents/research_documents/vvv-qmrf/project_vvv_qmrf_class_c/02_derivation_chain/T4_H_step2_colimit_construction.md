## Round 1 — Problem Isolation / Co lap Van de

### 1.1 Define — 3 Sub-Problems (SP1–SP3)

Step 2 must construct the colimit object from a finite diagram D with objects K_1, ..., K_N and K1-K8-preserving morphisms (embeddings) between them. The standard Set-colimit construction is:

```
K_colim = (∐_{i=1}^{N} K_i) / ~
```

where ~ is the equivalence relation generated by diagram morphisms. Three sub-problems emerge when this construction is applied to K-spaces:

| SP | Symptom | Manifestation |
|----|---------|---------------|
| **SP1** | t-field ambiguous in quotient | Different K_R have independent timestamp spaces T_R. Two tuples (k, i) and (k', j) with (k, i) ~ (k', j) may have t_i(k) ≠ t_j(k'). Which t does [k,i] carry? K1 t-injectivity may fail if the same t value appears from different K_R in the quotient. |
| **SP2** | V-field ambiguous — snapshot vs dynamic | V evolves: K4 default → K5 may fire → K7 closure freezes. The colimit is a static mathematical object. Which V does [k,i] carry? K8 guarantees V preservation at embedding time only. Post-embedding K5 dynamics are not captured by the static quotient. |
| **SP3** | <_colim may not be a partial order | <_colim = (∪_i ι_i(<_i) ∪ cross-rel_D)^+. Cycles can arise if cross-rel_D (Level 4 external input) conflicts with native K2 orders. The construction must produce a candidate order; cycle detection is a verification concern. |

### 1.2 Trace — 5-Why per Sub-Problem

#### SP1 — t-field (5-Why)

1. **Why is t([k]) ambiguous?** → Different K_R have independent T_R timestamp spaces; the quotient merges tuples from different K_R without a canonical timestamp normalization rule.
2. **Why do K_R have independent T_R?** → K2 defines <_R as a chain within each K_R; there is no axiom imposing a global clock across K-spaces.
3. **Why not add a global clock axiom?** → That would violate K ≠ H (K-space is registration-logic, not physical spacetime). A global clock is a ρ-side concept.
4. **Why can't we pick an arbitrary representative's t?** → The equivalence class [k,i] may have multiple representatives with different t values; arbitrary choice breaks well-definedness.
5. **Root cause:** K1 t-injectivity is an **intra-K_R** constraint. The quotient merges **inter-K_R** spaces. Step 2 must define a canonical t-assignment rule that: (a) is well-defined on equivalence classes, (b) preserves K1 t-injectivity in K_colim, and (c) does not require a global clock.

#### SP2 — V-field (5-Why)

1. **Why is V([k]) ambiguous?** → V is a temporal predicate (V_prov → V_final via K7); the colimit is an atemporal construction.
2. **Why not use V_final?** → K7 assigns V_final only after closure (pending(K_R, K_X) = ∅). The colimit construction is a mathematical operation that does not wait for K7 closure.
3. **Why not use "current" V?** → "Current" has no meaning for the colimit object — it is a static mathematical entity, not a running process.
4. **Why does K8 only guarantee V at embedding time?** → K8 is an embedding postulate: it guarantees the initial V snapshot when a tuple enters a new K-space, not immunity from future K5 invalidation.
5. **Root cause:** V is a **temporal predicate** (evolves via K4→K5→K7); the colimit is an **atemporal construction**. Step 2 must fix a specific temporal cross-section for V_colim. K8 gives us the natural choice: V at embedding time. Post-embedding V dynamics belong to Step 3 (K1-K8 preservation verification).

#### SP3 — Order (5-Why)

1. **Why might <_colim have cycles?** → cross_rel_D (external Level 4 input) may conflict with native K2 orders.
2. **Why is cross_rel_D external?** → Cross-structure temporal relations come from laboratory history (experimental protocol), not from K1-K8 axioms. T1 already established this pattern.
3. **Why can't Step 2 reject conflicting cross_rel_D?** → Step 2 constructs the colimit from given inputs; it does not adjudicate Level 4 inputs. That is Step 3's job.
4. **Why follow T1's pattern?** → T1 constructs K_joint as a **candidate**; AdmJoint **verifies** admissibility. Same separation: construct first, verify later.
5. **Root cause:** Construction and verification are separate concerns. Step 2 builds <_colim as a candidate relation; Step 3 verifies it satisfies K2 (strict partial order). If cycles exist, Step 3 rejects the candidate — the same pattern as T1 (K_joint candidate → AdmJoint check).

## Round 2 — Construction Design / Thiet ke Xay dung

### 2.1 Assumption: Diagram Commutativity

Step 2 constructs K_colim under the assumption that diagram D is **commutative**: for any two paths from K_i to K_j in D, the composite morphisms agree. This is the F7d global commutativity guard from T4. The non-commutative case is a Step 3 verification issue — if D is non-commutative, the equivalence relation ~ may be ill-defined, and Step 3 will reject the candidate.

This assumption is consistent with T4's statement: "the N-observer embedding diagram satisfies global overlap compatibility: shared K-state images and all embedding paths commute." Step 2 **constructs** under this condition; Step 3 **verifies** the condition is satisfied.

### 2.2 Step 2a — Disjoint Union (Carrier Set)

**Construction:**
```
U = ∐_{i=1}^{N} K_i = { (k, i) | i ∈ {1, ..., N}, k ∈ K_i }
```

Each element is tagged with its source K-space index i. This ensures that even if two K-spaces contain structurally identical tuples, they remain distinguishable in U.

**Properties:**
- U is a set (finite or countable, as each K_i is finite or countable by K1)
- The canonical injection ι_i^pre: K_i → U defined by ι_i^pre(k) = (k, i) is injective
- No K1-K8 structure is imposed on U yet — it is a bare set

### 2.3 Step 2b — Equivalence Relation ~

**Construction:**

The equivalence relation ~ on U is generated by the diagram morphisms:

```
For any morphism f: K_i → K_j in diagram D, and any k ∈ K_i:
  (k, i) ~ (f(k), j)
```

The full equivalence relation is the reflexive, symmetric, transitive closure:

```
(k, i) ~ (k', j)  iff  ∃ a zig-zag chain in D:
  K_i = K_{a0} → K_{a1} ← K_{a2} → ... ← K_{am} = K_j
  with morphisms f_1: K_{a0} → K_{a1}, f_2: K_{a2} → K_{a1}, ..., f_m: K_{a_{m-1}} → K_{am}
  such that composing these morphisms maps k to k'.
```

In category-theoretic terms, ~ is the equivalence relation generated by (k, i) ∼ (f(k), j) for every morphism f: K_i → K_j in D and every k ∈ K_i.

**Well-definedness check:**

Under the commutative diagram assumption:
- If (k, i) ~ (k', j) and (k, i) ~ (k'', j) via different paths, then k' = k'' (diagram commutes → all paths agree on the image of k)
- Transitivity holds by construction (equivalence relation closure)
- Symmetry holds by zig-zag (morphisms can go in either direction in the chain)

**K8 role:** K8 guarantees that f(k) preserves M, o, cert, t, V fields of k at embedding time. Therefore, if (k, i) ~ (k', j), the identified tuples share the same M, o, cert values. t and V may differ (see SP1, SP2 resolutions below).

### 2.4 Step 2c — Quotient Set K_colim

**Construction:**
```
K_colim = U / ~ = { [k,i] | (k,i) ∈ U }

where [k,i] = { (k',j) ∈ U | (k',j) ~ (k,i) }
```

**Canonical embedding ι_i: K_i → K_colim:**
```
ι_i(k) = [k,i]
```

Each ι_i sends a tuple k ∈ K_i to its equivalence class in K_colim. This is the standard colimit injection in Set.

### 2.5 Step 2d — Five Tuple Fields on K_colim

#### M, o, cert fields (trivial — K8 preservation)

For any equivalence class [k,i] ∈ K_colim:

```
M_colim([k,i]) = M_i(k)      where (k,i) is any representative of [k,i]
o_colim([k,i]) = o_i(k)
cert_colim([k,i]) = cert_i(k)
```

**Well-definedness proof:**
Let (k,i) and (k',j) be two representatives of the same class [k,i], so (k,i) ~ (k',j). By definition of ~, there exists a chain of diagram morphisms mapping k to k'. By K8 field preservation, every morphism in C_{K-space} preserves M, o, and cert values. Therefore M_i(k) = M_j(k'), o_i(k) = o_j(k'), cert_i(k) = cert_j(k'). The choice of representative does not matter. ✓

#### t field (SP1 resolution)

**Construction — Lexicographic t assignment:**

For any equivalence class [k,i] ∈ K_colim, let S = { (t_j(k'), j) | (k',j) ∈ [k,i] } be the set of (timestamp, source-index) pairs of all representatives. Define:

```
t_colim([k,i]) = the lexicographically smallest (t, j) ∈ S
```

where (t_1, j_1) <_lex (t_2, j_2) iff t_1 < t_2, or (t_1 = t_2 and j_1 < j_2).

**Properties:**
- **Well-defined:** Every non-empty finite set of (t, j) pairs has a unique lexicographic minimum (total order on pairs). Each equivalence class has at least one representative, so S is non-empty.
- **Canonical:** The choice is deterministic — given the same equivalence class, the same canonical t is always selected.
- **t-injectivity preserved in K_colim:** If [k,i] ≠ [k',j], their canonical representatives have different (t, j) pairs → t_colim([k,i]) ≠ t_colim([k',j]). Thus t_colim is injective on K_colim, satisfying K1's t-injectivity constraint.
- **No global clock required:** The lexicographic order uses only the existing timestamp spaces T_i and source indices — no new physical time structure is introduced.

**Why this works for K1:**
K1 requires t restricted to K_R to be injective. In K_colim, t_colim is injective because: (a) each equivalence class gets a unique canonical (t, j) pair; (b) the lexicographic order is a total order on pairs; (c) different equivalence classes necessarily have different canonical pairs (otherwise they'd have the same canonical representative and would be the same class).

**SP1 resolution status: RESOLVED.** t_colim is well-defined, injective, canonical, and requires no global clock.

#### V field (SP2 resolution)

**Construction — Embedding-time snapshot:**

```
V_colim([k,i]) = V_a(k*) where (k*, a) is the canonical representative
```

selected by the lexicographic t-assignment rule above.

**Justification:**
- K8 guarantees that when any tuple is embedded via a C_{K-space} morphism, V is preserved at the moment of embedding: V_target(i(k)) = V_source(k) at t_embed.
- By selecting the canonical representative (the one with the earliest (t,j) pair), we anchor V_colim to the "first" K-space in which this registration event appears.
- This is a **snapshot** — V_colim captures V at embedding time. It does NOT track subsequent K5 dynamics. That is Step 3's responsibility.

**Well-definedness check:**
Since V_colim is defined on the canonical representative (which is unique per equivalence class), it is trivially well-defined — no choice ambiguity.

**Why not V_final?**
K7 assigns V_final only after closure. The colimit is a mathematical construction performed at a logical level prior to K7 evaluation. Using V_final would create a hidden dependency on K7 timing. Using V at embedding time respects the K8 guarantee and keeps Step 2 independent of K7 closure state.

**SP2 resolution status: RESOLVED.** V_colim is well-defined as embedding-time snapshot via canonical representative. Post-embedding K5 dynamics are deferred to Step 3.

### 2.6 Step 2e — Partial Order <_colim

**Construction:**

```
Let native_orders = ⋃_{i=1}^{N} { (ι_i(k), ι_i(k')) | k <_i k' in K_i }
Let cross_rel_D = { (ι_i(k), ι_j(k')) | cross-structure temporal relations from Level 4 D_joint }
                   [external input — same pattern as T1]

<_colim = (native_orders ∪ cross_rel_D)^+
```

where (·)^+ denotes transitive closure.

**Explicit definition:**
For [k,i], [k',j] ∈ K_colim with [k,i] ≠ [k',j]:

```
[k,i] <_colim [k',j]  iff  ∃ a finite sequence:
  [k,i] = x_0, x_1, ..., x_m = [k',j]
such that for each r ∈ {0, ..., m-1}:
  (x_r, x_{r+1}) ∈ native_orders  ∨  (x_r, x_{r+1}) ∈ cross_rel_D
```

**Properties:**
- **Irreflexive:** By construction — only pairs with [k,i] ≠ [k',j] are considered
- **Transitive:** By construction — transitive closure ensures this
- **Candidate only:** Step 2 constructs this relation; Step 3 verifies it is a strict partial order (no cycles) and satisfies K2 axioms

**Pattern consistency with T1:**
T1 constructs <_joint as (i_A(<_A) ∪ i_B(<_B) ∪ cross-rel)^+ — exactly the same transitive closure pattern, generalized from N=2 to arbitrary N. This is a direct generalization, not a new construction method.

**SP3 resolution status: PARTIALLY RESOLVED.** <_colim is constructed as a candidate relation using the same transitive closure pattern as T1. Cycle detection (whether <_colim is a valid strict partial order) belongs to Step 3 verification.

## Round 3 — Verification Gates & Integration / Cong Xac minh & Tich hop

### 3.1 Verification Gates

#### G1 — Tuple fields well-defined on ~

**Check:** For any equivalence class [k,i], verify that all representatives agree on M, o, cert values.

**Proof:** If (k,i) ~ (k',j), then ∃ chain of C_{K-space} morphisms mapping k to k'. By K8 field preservation, each morphism preserves M, o, cert. By induction along the chain, M_i(k) = M_j(k'), o_i(k) = o_j(k'), cert_i(k) = cert_j(k'). ✓

**Status: PASS.**

#### G2 — t_colim well-defined and injective

**Check (well-defined):** Lexicographic minimum on finite set S = {(t_j(k'), j) | (k',j) ∈ [k,i]} exists and is unique.

**Proof:** S is non-empty (at least (t_i(k), i) ∈ S). Lexicographic order on pairs is a strict total order. Any finite non-empty subset of a totally ordered set has a unique minimum. ✓

**Check (injective):** If [k,i] ≠ [k',j], then t_colim([k,i]) ≠ t_colim([k',j]).

**Proof:** Let (t_a, a) = t_colim([k,i]) and (t_b, b) = t_colim([k',j]). If (t_a, a) = (t_b, b), then both classes share the same canonical representative, meaning they contain the same element (k*, a) = (k*, b). Then [k,i] = [k*, a] = [k*, b] = [k',j], contradiction. ✓

**Status: PASS.**

#### G3 — V_colim internally consistent

**Check:** V_colim is well-defined via canonical representative.

**Proof:** V_colim([k,i]) is defined as V_a(k*) where (k*, a) is the unique canonical representative from G2. Since the canonical representative is unique per class, V_colim is a function (single-valued). ✓

**Check (K8 consistency):** For the canonical embedding ι_i: K_i → K_colim, V_colim(ι_i(k)) captures the embedding-time V.

**Proof:** ι_i(k) = [k,i]. Its canonical representative (t*, j) is the lexicographically smallest among all (t, j) in [k,i]. If (t_i(k), i) itself is the canonical representative, V_colim([k,i]) = V_i(k) directly. If a different representative (k', j) with earlier timestamp is canonical, then by K8 along the morphism chain: V_i(k) at t_embed(i) = V_j(k') at t_embed(j). So V_colim still equals the embedding-time V. ✓

**Status: PASS.**

#### G4 — <_colim construction is deterministic

**Check:** <_colim is uniquely determined by its inputs (native orders + cross_rel_D).

**Proof:** Both native_orders and cross_rel_D are well-defined sets of pairs. Transitive closure of a finite union of relations is unique. ✓

**Status: PASS.**

#### G5 — ι_i: K_i → K_colim is a valid C_{K-space} morphism

**Check (field preservation for M, o, cert):** M_colim(ι_i(k)) = M_colim([k,i]) = M_i(k) by G1. Same for o, cert. ✓

**Check (t preservation — refined):** t_colim(ι_i(k)) may differ from t_i(k) if a representative with earlier (t,j) exists in [k,i]. This is a structural refinement: ι_i preserves the **set** of t-values S([k,i]) = {t_j(k') | (k',j) ∈ [k,i]}, of which t_i(k) is a member. t_colim selects a canonical element from S without losing information. The original tuple's t is retained in the class; t_colim provides a deterministic label. This is not a violation — K8 t-preservation applies to the embedding target, and K_colim's t-assignment rule (lexicographic minimum) defines the target's labeling convention.

**Check (order preservation):** k1 <_i k2 ⇒ ι_i(k1) <_colim ι_i(k2).

**Proof:** ι_i(k1) = [k1,i], ι_i(k2) = [k2,i]. Since k1 <_i k2, (ι_i(k1), ι_i(k2)) ∈ native_orders ⊆ <_colim. ✓

**Check (V preservation):** V_colim(ι_i(k)) equals V_i(k) at embedding time (G3). ✓

**Check (cert intrinsic):** cert_colim(ι_i(k)) = cert_i(k) = σ_i(M_i(k)) by G1 + K3. ✓

**Status: PASS (with t-preservation refinement noted).**
