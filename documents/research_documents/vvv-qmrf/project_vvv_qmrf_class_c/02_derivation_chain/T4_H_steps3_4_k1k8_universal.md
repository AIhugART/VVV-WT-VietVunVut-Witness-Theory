## Preliminary Lemma: T-PRES

**Lemma T-PRES** (Temporal Field Preservation under Morphisms):

*Any morphism f: K_i → K_j in C_{K-space} satisfies:*

```
t_j(f(k)) = t_i(k)   for all k ∈ K_i
```

**Proof:** The morphism definition in C_{K-space} (Step 2, G5) states explicitly:

> "ι_i: K_i → K_colim preserves all 5 fields: M, o, cert, t, V (K8)"

Since K8-preservation is the defining condition on morphisms, and t is one of the 5 fields, every morphism in C_{K-space} preserves t as an equality (not just an inequality). □

**Corollary T-REP** (Representative Temporal Invariance):

*All representatives (k', j) of any equivalence class [k, i] share the same t value:*

```
t_j(k') = t_i(k)   for all (k', j) ~ (k, i)
```

**Proof:** The equivalence relation ~ is generated by: (k, i) ~ (f(k), j) whenever f: K_i → K_j is a morphism and f(k) = k'. By T-PRES, t_j(f(k)) = t_i(k). Transitivity and symmetry preserve equality throughout the equivalence class. □

**Consequence for K_colim:** The field t_colim([k, i]) := t_i(k) is well-defined (independent of representative choice, by T-REP).

## Step 3: K1–K8 Verification for K_colim

### K1 — Act-Result Co-instantiation

**Claim:** Each element of K_colim is a 5-tuple (M, o, cert, t, V) with act M and result o co-instantiated.

**Proof:** Every element [k, i] ∈ K_colim inherits its tuple fields from k ∈ K_i. Since k satisfies K1 in K_i (act and result co-instantiated), and the quotient map preserves all 5 fields (Step 2, G5), [k, i] carries the same tuple with the same co-instantiation property. The t_colim and V_colim definitions assign canonical values derived from the inherited fields, not new independent fields. □

**K1: PASS**

### K2 — Temporal Injectivity (Acyclicity)

**Claim:** The relation <_colim on K_colim is a strict partial order (irreflexive, transitive, acyclic).

**Proof in 4 steps:**

**(a) Native orders:** Within each K_i, k <_i k' implies t_i(k) < t_i(k') (K2 in K_i). Under the colimit, [k, i] <_colim [k', i] iff k <_i k'. Since t_colim([k, i]) = t_i(k) by T-REP, we have t_colim([k, i]) < t_colim([k', i]) for all native-order pairs. No cycles within any K_i component.

**(b) Cross-component relation D:** Step 2 introduces cross_rel_D for pairs ([k, i], [k', j]) with i ≠ j, defined via physical causal precedence of the registration events. The causal precedence relation on physical events is a strict partial order (special relativity / standard temporal assumptions). D is therefore acyclic.

**(c) Transitive closure:** <_colim = (native_orders ∪ D)^+. A cycle in the transitive closure would require a sequence:

```
[k_1, i_1] <_colim [k_2, i_2] <_colim ... <_colim [k_n, i_n] <_colim [k_1, i_1]
```

Each step is either native-order (increases t_colim) or D-order (increases t_colim by physical causality). The total sequence would require t_colim([k_1, i_1]) < t_colim([k_1, i_1]) — a contradiction.

**(d) Conclusion:** <_colim is irreflexive and acyclic. Combined with transitivity (closure definition), it is a strict partial order satisfying K2. □

**K2: PASS**

### K5 — Cross-Registration Interaction (Incommensurability)

**Claim:** K5 (bot_K incommensurability) holds in K_colim.

**Proof in 4 parts:**

**(A) Inherited within-K_i incommensurability:** For [k, i] and [k', i] from the same component, if k ⊥_K k' in K_i, then [k, i] ⊥_K [k', i] in K_colim. This follows because K5 conditions (i)–(iii) are preserved by K8-morphisms (Step 1), and the colimit quotient does not identify incompatible states from the same K_i (the equivalence relation only identifies via morphism images, and K8-morphisms preserve K5 status).

**(B) Cross-component incommensurability:** For [k, i] and [k', j] with i ≠ j, K5 fires when:
- (i) K_i ≠ K_j (distinct observer contexts) — satisfied by i ≠ j
- (ii) o([k, i]) ≠ o([k', j]) — checked from tuple fields
- (iii) t_colim([k, i]) and t_colim([k', j]) are co-temporal (within the relevant window)

When K5 fires, bot_K relation is registered in K_colim. This is new cross-space incommensurability not present in individual K_i, and is structurally consistent with K5's design (K5 applies across K-spaces).

**(C) Non-contradiction (V monotone dynamics):** K5 firing sets V_colim([k', j]) = 0 for the invalidated element. V transitions are monotone (V: 1 → 0 only, never 0 → 1) by K4 + K7 closure. This ensures K5 does not create contradictions: once V = 0, the element is marked invalid, not removed.

**(D) Consistency with K2:** K5 firing adds bot_K pairs but does not add order pairs. <_colim is unaffected by K5. The acyclicity proof in K2 is independent of K5 status. □

**K5: PASS**

A chain [k, i] Auth [k', j] Auth [k'', l] does NOT imply [k, i] Auth [k'', l] — the colimit inherits this non-transitive property from K6 in each K_i. □

No morphism in C_{K-space} can increase V from 0 to 1 (K8-preserving morphisms preserve V at embedding time, and V = 0 states are not re-validated).

## Step 4: Universal Property

**Claim (Universal Property):** For any K-space X and any family of K8-preserving morphisms f_i: K_i → X compatible with the diagram D (i.e., f_j ∘ f_{ij} = f_i for all morphisms f_{ij}: K_i → K_j in D), there exists a unique K8-preserving morphism u: K_colim → X such that u ∘ ι_i = f_i for all i.

---

### UP-1: Construction of u

Define:

```
u([k, i]) := f_i(k)
```

---

### UP-2: Well-Definedness

We must show u is independent of the choice of representative.

If (k, i) ~ (k', j), then by definition of ~, there exists a morphism chain f_{ij}: K_i → K_j (or its composition) with f_{ij}(k) = k'.

By compatibility: f_j(f_{ij}(k)) = f_i(k) (diagram commutativity condition on {f_i}).

Therefore: u([k', j]) = f_j(k') = f_j(f_{ij}(k)) = f_i(k) = u([k, i]). □

---

### UP-3: K8-Preservation of u

We must show u preserves all 5 tuple fields (M, o, cert, t, V).

Each f_i: K_i → X is K8-preserving by assumption. Therefore:

- M_X(u([k, i])) = M_X(f_i(k)) = M_i(k) = M_colim([k, i]) ✓
- o_X(u([k, i])) = o_i(k) = o_colim([k, i]) ✓
- cert_X(u([k, i])) = cert_i(k) = cert_colim([k, i]) ✓
- t_X(u([k, i])) = t_i(k) = t_colim([k, i]) ✓  (by T-PRES applied to f_i)
- V_X(u([k, i])) = V_i(k) = V_colim([k, i]) ✓

All 5 fields preserved. u is K8-preserving. □

---

### UP-4: Commutativity u ∘ ι_i = f_i

For any k ∈ K_i:

```
(u ∘ ι_i)(k) = u(ι_i(k)) = u([k, i]) = f_i(k)
```

Therefore u ∘ ι_i = f_i for all i. □

---

### UP-5: Uniqueness of u

Suppose u': K_colim → X is another K8-preserving morphism with u' ∘ ι_i = f_i for all i.

For any [k, i] ∈ K_colim:

```
u'([k, i]) = u'(ι_i(k)) = (u' ∘ ι_i)(k) = f_i(k) = u([k, i])
```

Therefore u' = u. □
